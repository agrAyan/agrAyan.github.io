# Ayan Agrawal Portfolio - Clean Edition

A clean, recruiter-friendly senior software engineer portfolio for GitHub Pages.

## Publish
1. Upload `index.html` and `styles.css` to your GitHub Pages repository.
2. Export your resume to PDF and save it as `Ayan_Agrawal_Resume.pdf` in the same directory.
3. In GitHub: Settings -> Pages -> Deploy from branch -> `main` -> `/ (root)`.

LinkedIn is configured as: `https://www.linkedin.com/in/ayan-agrawall/`
